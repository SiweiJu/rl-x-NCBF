# T14: does the world model predict falls? (P1, Q1 / decision point A) — agent wm-model

Status: **done** (2026-10-27). **Decision point A: passed** on accuracy (WM AUC > critic AUC, CI excludes 0) and on
speed with the gated VJP (2.5× per step) and per training iteration (2.2×); the full-VJP shield is 3.6× per step.

## Setup
- **States:** the oracle decision points of the 6 held-out T06b checkpoints (wm-data v1 `test/`: ii_h25 seeds 145 / 245,
  ncbf_h1 145 / 245, ppo 1342 / 1442) × 5 settings (action noise p ∈ {0, 0.4, 0.8}, push p ∈ {0.005, 0.02}): every
  10 steps, the first 256 envs of each shard (100 × 256 per shard). States with stale IMU groups are left out
  (episode step 0, or right after a shock / DR step; see T13).
- **u0** = `oracle_u0` = the checkpoint's policy on the noise-free o(x⁺_t), the first action of the oracle branch.
- **Predictors** (all as V = logit P̂(no event within H), P̂_fail = sigmoid(−V)):
  1. **WM:** the T13 world model's H-step imagination from x⁺_t (u0 through the env delay, then the checkpoint's
     deterministic policy on o(x̂), recorded ξ), the analytic margin per step and log P̂ = Σ_j −softplus(−ℓ_j / T_ℓ)
     (plan 4.5), T_ℓ ∈ {0.1, 0.3, 1, 3}. ℓ = `margin_fall` (min of IMU height / 0.05 m and the qvel margin / 10 m/s;
     at eval the T06b height threshold is 0) or `margin_fall_physical` (IMU height − 0.5 h_nom over 0.05 m, tilt 1 rad
     − √(roll² + pitch²) over 0.2 rad).
  2. **Critic:** the same checkpoint's T06b safety critic, h(s, u0) → ensemble-mean P(safe), computed exactly as
     `PPO._safety_prediction`: input = `oracle_obs_full[t]` (the noisy full observation the policy saw) at
     `ncbf_observation_indices`, the action u0, and the latent z = encoder(`oracle_history_stack[t]`) (the env's
     history stack at t). Also reported: wm-data's stored value with u_policy[t] (policy on the noisy obs) instead of u0.
     All 6 checkpoints have a critic (the T06b ppo runs train one without using it); the WM-vs-critic comparison uses
     the 2 ii_h25 checkpoints (the critic that shields in training).
  3. **Persistence margin:** the margin of x⁺_t held for H steps (same V formula).
- **Labels:** oracle (shock-free MJX branch with u0, no command resampling, noise-free obs; main) and actual (the
  recorded episode), for the fall (termination) event and the physical fall event, H ∈ {10, 25} (main 25).
- **Metrics:** AUC and Brier with 95 % cluster-bootstrap CIs over episodes (200 resamples); lead time of actual events
  (earliest decision point within 50 steps before the event with P̂_fail > 0.5, or above the threshold that gives 5 %
  FPR on the label-0 states; 10-step resolution because decision points are 10 steps apart); splits by setting and
  by checkpoint.
- Code: `experiments/pncbf/wm/t14_collect.py` (per checkpoint, inside the runner), `t14_analyze.py`, `t14.sbatch`;
  `gate_wm.py` / `gate_summary.py` for |∇_u V| and the gate.

### Margin temperature T_ℓ (WM k16, all checkpoints, oracle / actual fall H = 25; gate_summary, ~3k states for ∇)
| T_ℓ | AUC oracle / actual | Brier oracle / actual (const 0.039 / 0.041) | V q1 / q5 / q50 | share with \|V\| < 2 | median \|∇_u V\| band / elsewhere |
|---|---|---|---|---|---|
| 0.1 | 0.946 / 0.908 | 0.011 / 0.016 | −178 / 27.6 / 27.6 | 0.18 % | 9.0 / 0 |
| 0.3 | 0.995 / 0.977 | 0.010 / 0.014 | −61 / 12.3 / 21.7 | 0.40 % | 4.8 / 0.47 |
| **1** | **0.995 / 0.976** | **0.0085 / 0.013** | −24 / 2.0 / 4.3 | 1.5 % | 0.91 / 0.14 |
| 3 | 0.994 / 0.974 | 0.71 / 0.71 | −18 / −3.5 / −1.8 | 74 % | 0.10 / 0.16 |
- ℓ = `margin_fall` is in units of the 5 cm height scale (and 10 m/s for qvel); not normalized by h_nom.
- T_ℓ = 0.1 is almost binary (V saturates at +27.6; ∇ = 0 away from the boundary); T_ℓ = 3 is miscalibrated
  (25 steps of a per-step hazard ≈ 0.1 put every state at V < 0) and would need a margin offset.
- **Recommendation: T_ℓ = 1 for the fall event** (best Brier, nonzero slope everywhere, 6× steeper in the band);
  **T_ℓ = 0.3 for the physical event** (its margin sits ~3.8 units above 0 for a standing robot; at T_ℓ = 1 the
  Brier is 0.17, at 0.3 it is 0.012). A per-event offset b in −softplus(−(ℓ − b)/T) would decouple scale and
  calibration (not tried).
- Gate (γ_c = 0 logit = p_c 0.5, rough stand-in; 256-env batches per decision step): for T_ℓ ≤ 1, no state with
  V < γ_c is outside the top 25 % lowest-V envs, and no step has more than 25 % of its envs below γ_c (k16 and k25).

### Speed (decision point A; T13, RTX A5000, 1024 envs = T06b, WM 512×3, H = 25)
- Per env step (PPO env step 4.24 ms): full VJP f32 15.1 ms = 3.6× (fails 3×); **gated VJP 25 % + bf16 matmuls
  10.5 ms = 2.5×** (passes); gated 25 % f32 12.0 ms = 2.8×. bf16 changes no k-step error by more than 0.5 %.
- Per training iteration (T06b ppo 2.83 s): PPO + WM shield gated bf16 4.14 s + 50 WM updates (k16, ~41 ms each)
  ≈ 6.2 s = **2.2×** (1.7× T06b ii_h25).

## Caveats
- States are the oracle decision points only (every 10 steps, first 256 envs); lead times have 10-step resolution.
- The WM sees the recorded x⁺_t; states with stale IMU (episode start, right after a shock) are excluded (8,918 of 768,000 = 1.2 %).
- γ_c = 0 for the gate is a stand-in; the shield's real threshold depends on P2's η/γ_c choice.
- k16 vs k25 was chosen on these test checkpoints (two candidates, small difference in favour of k16; by 25-step
  state error k25 is better), so treat that choice as mild test-set selection. Both pass decision A.
