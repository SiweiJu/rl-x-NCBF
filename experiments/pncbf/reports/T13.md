### Model details (all switches; defaults in brackets)
- Input: (x⁺ without base_xy/base_yaw, ũ, ξ) normalized; `use_xi` [on]. Output: normalized delta over all dims except
  `last_action`. `last_action` of x̂⁻_{t+1} is set to the chosen undelayed u_t (`last_action_source=chosen`; matches
  the env's previous-action obs; `applied` / `predict` available).
- base_xy / base_yaw: never an input (translation/yaw invariance); their delta is predicted in the heading frame of
  x_t and rotated, yaw wrapped. So the world-frame (wm-data) and window-frame conventions both work.
- Loss: mean over windows, k_train steps and predicted dims of ((x̂⁻ − x⁻)/σ_Δ)², σ_Δ = per-dim std of the one-step
  delta (floor 1e-3). **Method A** [default]: at a step with `perturbed_next | dr_resampled_next`, continue from the
  recorded x⁺ (teacher forcing). **Method B** (`--method B`): windows with a shock between two of their steps are
  masked. Ensemble members each roll out on their own predictions; losses are summed.
- Optimizer: Adam 2e-4, global clip 1.0, batch 4096 windows, neg (near-failure) share 0.3, 50 updates per jit call.
- `rollout(wm, bundle, x0, xi, delay_buffer0, u0, policy_fn, H, delay_step_fn, open_loop)`: u0 goes through
  `delay_step` at t, then u_j = policy_fn(x̂_j); returns x̂_{t+1..t+H} (H, N, S). Closed loop [default]: ∇_{u0} also
  flows through the policy's reaction; `open_loop=True` stops the gradient at the policy outputs (same values).
  With wm-data: `delay_step_fn = lambda b, u: wm_state.delay_step(b, u, wm_state.delay_steps_from_xi(xi_full, xl))`,
  `policy_fn = lambda x: policy(full_obs_fn(x, command, xi_full))`, WM ξ = `xi_full[..., meta["schema"]["xi_active"]]`.

### Data (wm-data schema `pncbf-p1-wmdata/v1`)
- Split from `meta.json` `split` (test = seeds 145/245, ppo 1342/1442); without it, `--heldout_pattern`.
- Compact in memory: x⁺_{t+1} = x_plus[t+1] inside a window (not loaded); x⁻_{t+1} stored only where it differs from
  x_plus[t+1] (shock / DR / done rows; the loader checks every row and stores all mismatches); ξ = xi_table[xi_idx],
  only the dims that vary on the training data (`xi_active`, saved in the bundle).
- Windows starting at `episode_step == 0` are masked (stale IMU values after a reset).
- Logged checks: last_action(x⁻_{t+1}) == u_cmd_t; rows where x⁻_{t+1} ≠ x⁺ of the next row outside shock/done rows.

## Speed (first numbers; jobs 182788 / 182789 @ 1433ae6, gn05/gn06)
WM 3×512 (random params, wm-data state layout, ξ dim 32 stub), H = 25, closed loop, float32. T06b policy from the
ii_h25 seed-42 checkpoint, obs/margin stubs (wm_state was not on that commit). Env = T06b config, flat terrain.

| | 1024 envs (T06b) | 4096 envs |
|---|---|---|
| env step + policy (PPO rollout step, no shield) | 4.06 ms | 9.33 ms |
| env step + policy + critic shield (ii_h25) | 4.75 ms | 11.95 ms |
| WM rollout, forward only | 4.6 ms | 12.7–13.7 ms |
| WM rollout + one VJP w.r.t. u0 | 15.0–15.2 ms | 45.2–49.0 ms |
| env step + policy + WM rollout/VJP (in the PPO scan) | 18.3 ms | 59.8 ms |
| ratio (WM rollout+VJP) / (env step + policy) | **3.7×** | **4.8–5.2×** |

4096). Running: 182813 (matrix: open loop, bfloat16, H ∈ {10,16,25}, width 256/1024, depth 4, ensemble 5) and
